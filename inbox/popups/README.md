# inbox/popups/

The **idle popup** ("still playing?" with the green button), the **logged-out popup**, the **Play Now** screen, and any **unknown dialog** (trade / buddy request etc.). Full-window screenshots.

**Naming:** e.g. `popup_still_here.png`, `popup_logged_out.png`, `play_now.png`, `unknown_trade.png`. Optional tags: `__question`, `__locked`, `__reveal_correct`, `__reveal_wrong`, `__popup_still_here`, `__popup_logged_out`, `__party_panel` (see `inbox/README.md`).

Files are moved to `inbox/_processed/` after ingest.
