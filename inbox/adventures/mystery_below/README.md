# inbox/adventures/mystery_below/

Recordings of **The Mystery Below**, start to finish: the adventure menu, the Zios gate, the moth cave, the torches, both mirror puzzles, the button room, the obelisk and the prize chests. **Solo, Normal mode**, same animal every time, so the bot can learn one fixed route. Prefer `learn --target mystery_below` (it logs your keys and clicks too); OBS recordings work as well.

Files are moved to `inbox/_processed/` after ingest.
