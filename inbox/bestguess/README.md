# inbox/bestguess/

PNG screenshots and OBS recordings (.mp4 / .mkv) of the **Best Guess Game**. Record the whole thing: joining, several rounds, the reveal, the gem counter. A land animal please (underwater ones render broken there).

**Naming:** anything; e.g. `bg_2026-10-26_1.mp4`, `bg_001__question.png`. Optional tags: `__question`, `__locked`, `__reveal_correct`, `__reveal_wrong`, `__popup_still_here`, `__popup_logged_out`, `__party_panel` (see `inbox/README.md`).

Files are moved to `inbox/_processed/` after ingest.
