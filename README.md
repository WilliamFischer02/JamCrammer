# JamCrammer

Screen-only automation and "first contact" learning tool for Animal Jam Classic (desktop app). See `docs/KICKOFF.md` for the full spec.

## Quick start

```powershell
powershell -ExecutionPolicy Bypass -File scripts\setup.ps1
run.bat
```

CLI: `.venv\Scripts\python -m jamcrammer --help`

Full walkthrough (first launch → onboarding → Learn → calibrate → farm) arrives with milestone M11.
